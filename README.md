MlLibScala

MlLibScala to lekka biblioteka programistyczna napisana w języku Scala, służąca do uczenia maszynowego. Projekt skupia się na implementacji popularnych algorytmów ML od podstaw, kładąc nacisk na czytelność kodu oraz wykorzystanie programowania funkcyjnego i operacji macierzowych.

Funkcjonalności:

Biblioteka oferuje implementacje następujących modeli:

Linear Regression (Regresja Liniowa): Przewidywanie wartości ciągłych przy użyciu optymalizacji parametrów modelu.

Logistic Regression (Regresja Logistyczna): Klasyfikacja binarna z wykorzystaniem funkcji aktywacji (Sigmoid).

Matrix Math Engine: Własna implementacja operacji na macierzach i wektorach, niezbędna do obliczeń numerycznych w algorytmach ML.

Stos technologiczny:

Język: Scala

Narzędzie budowania: SBT (Scala Build Tool)

Główne koncepty: Programowanie funkcyjne, Algebra liniowa, Gradient Descent.
